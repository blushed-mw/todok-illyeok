# 🗓️ 토독 일력 (Todok Illyeok)

> 바탕화면에 붙여 두고 **하루에 한 장씩 토독 뜯어 쓰는** 작은 일력 위젯

매일 아침 종이를 톡톡 뜯으며 새로운 오늘을 맞이하고,
옆으로 살짝 기울여 **올해 남은 종이 두께**를 눈으로 확인해 보세요. 📄✨

---

## ✨ 주요 기능

| | 기능 | 설명 |
|---|---|---|
| ✂️ | **한 장씩 뜯기** | 종이를 **5번 톡톡** 누르면 절취선을 따라 한 장이 뜯겨 떨어져요 |
| 🐢 | **정직한 하루** | 며칠 안 뜯었다면 밀린 만큼 쌓여 있어요. 한 번에 하루씩만 넘어가요 |
| 🔄 | **기울여 보기** | 종이를 좌우로 끌면 달력이 돌아가며 옆면(남은 종이 더미)이 보여요 |
| ⏳ | **올해 남은 날** | 기울이면 "올해가 N일 남았어요"가 함께 떠요 |
| 📅 | **한눈에 보는 날짜** | 큰 날짜, 월·요일 배지, 이번 달 미니 달력, 음력 날짜 |
| 📝 | **하루 메모** | 그날 종이에 짧은 메모(40자)를 적어 둘 수 있어요 |
| 🟨 | **뜯기 알림** | 뜯을 종이가 남아 있으면 종이 왼쪽에 노란 인덱스 스티커가 팔랑거려요 |
| 🎉 | **연말 작별 페이지** | 12월 31일을 뜯으면 `BYE 20XX!`와 함께 해마다 다른 새해 인사가 나와요 |
| 🚀 | **자동 실행** | 설치하면 컴퓨터를 켤 때마다 자동으로 떠요 (메뉴에서 끌 수 있어요) |
| 📌 | **항상 위에** | 다른 창 위에 떠 있고, 초록 제본 부분을 잡고 원하는 곳으로 옮길 수 있어요 |

## 📥 다운로드

👉 **[최신 버전 받기 (Releases)](https://github.com/blushed-mw/todok-illyeok/releases/latest)**

내 컴퓨터에 맞는 파일 **하나만** 받으면 돼요.

| 내 컴퓨터 | 받을 파일 | 확인 방법 |
|---|---|---|
| 🪟 **Windows** (10 / 11) | `Todok-Illyeok-Setup-x.y.z.exe` | — |
| 🍎 **맥 – Apple 실리콘** (M1·M2·M3·M4…) | `Todok-Illyeok-x.y.z-arm64.dmg` |  → 이 Mac에 관하여 → 칩이 **Apple M…** |
| 🍎 **맥 – Intel** | `Todok-Illyeok-x.y.z-x64.dmg` |  → 이 Mac에 관하여 → 프로세서가 **Intel** |

> 💡 `x.y.z`는 버전 번호예요 (예: `0.1.2`).

## 🪟 Windows 설치

1. `Todok-Illyeok-Setup-x.y.z.exe`를 실행해요.
2. **"Windows의 PC 보호"** 파란 창이 뜨면 → **추가 정보** → **실행** 을 눌러요.
   > 개인이 만든 앱이라 코드 서명이 없어서 나오는 안내예요. 🙂
3. 설치가 끝나면 화면에 토독 일력이 떠요! 원하는 자리로 옮겨 두세요.
4. 작업 표시줄 오른쪽 아래 **트레이 아이콘**(^ 안쪽)에서 메뉴를 열 수 있어요.

## 🍎 맥 설치

1. 내 맥에 맞는 `.dmg`를 열고, **토독 일력** 아이콘을 **응용 프로그램(Applications)** 폴더로 끌어다 놓아요.
2. 응용 프로그램에서 **토독 일력**을 실행해요.
3. **"확인되지 않은 개발자"** 또는 **"손상되었기 때문에 열 수 없습니다"** 가 뜨면:
   - **방법 A** — 토독 일력 아이콘을 **우클릭 → 열기 → 열기**
   - **방법 B** — 그래도 안 되면 **터미널**을 열고 아래를 붙여넣기:
     ```bash
     xattr -cr "/Applications/토독 일력.app"
     ```
4. 맥에서는 Dock에 아이콘이 없어요. 화면 위 **메뉴 막대의 토독 일력 아이콘**으로 조작해요.

## 🖱️ 사용법

| 하고 싶은 것 | 이렇게 해요 |
|---|---|
| 오늘 종이 뜯기 | 종이를 **5번 클릭** ✂️ |
| 남은 두께 보기 | 종이를 누른 채 **좌우로 드래그** 🔄 |
| 메모 쓰기 | 아래 **MEMO** 줄을 클릭하고 입력 (자동 저장) 📝 |
| 위젯 옮기기 | 위쪽 **초록 제본 부분**을 잡고 드래그 📌 |
| 새해 시작 | 작별 페이지가 뜨면 **톡** 누르기 🎉 |

> 이미 오늘 날짜까지 다 뜯었다면 종이가 도리도리 흔들려요. 내일 또 만나요! 👋
